# Менеджер задач (Task Manager)

Консольное приложение на Java для управления списком задач.
Учебный проект: отработка ООП, коллекций, обработки исключений и работы с файлами.

## Возможности
- добавление задач с названием, описанием, приоритетом и дедлайном;
- просмотр списка с сортировкой (сначала невыполненные, затем по приоритету и сроку);
- отметка задачи выполненной;
- удаление задачи;
- автоматическое сохранение в файл `tasks.txt` и загрузка при следующем запуске.

## Структура проекта
- `Main.java` — консольный интерфейс и меню (взаимодействие с пользователем);
- `TaskManager.java` — бизнес-логика: управление коллекцией задач;
- `Task.java` — модель одной задачи;
- `Priority.java` — перечисление приоритетов;
- `TaskStorage.java` — сохранение и загрузка из файла;
- `TaskNotFoundException.java` — собственное исключение.

Архитектура построена на разделении ответственности: ввод/вывод, бизнес-логика
и хранение данных вынесены в отдельные классы и не зависят друг от друга.

## Запуск
Нужен установленный JDK 17 или новее (проект писался на JDK 21).

```bash
# компиляция (из корня проекта)
javac -d out src/taskmanager/*.java

# запуск
java -cp out taskmanager.Main
```

Данные сохраняются в файл `tasks.txt` рядом с местом запуска программы.
